# 对话框系统

## 说明 
1. 交互时调用函数呼出对话框
2. 对话框点击后到下一句话，最后一句话后结束
3. 关于函数`SetDialogueBox`这个写在交互接口内，具体请参考PickUP脚本  
传入两个string数组，和页面数即可在交互时调出
4. 注意如果这个物体后续需要被摧毁，务必参考PickUp脚本内的写法，将该协程函数`SetDialogueBox`执行完后再执行摧毁，不然可能会出现按钮失灵的情况

``` cs
public class PickUp : MonoBehaviour , IInteractable
{
    public Collider2D Collider { get; private set; }
    public void Awake()
    {
        Debug.Log("PickUp组件可以用");
        Collider = GetComponent<Collider2D>();
    }
    public void Interact(PlayerInteractor player)
    {
        
        StartCoroutine(InteractCoroutine());
        
    }
    private IEnumerator InteractCoroutine()
    {
        Debug.Log("触发接口了");
        string s1 = "物品名：钥匙";
        string s2 = "物品名：门";
        string s3 = "这个可以用来开门";
        string s4 = "这个可以需要用钥匙打开";
        string[] strings1 = {s1,s2};
        string[] strings2 = {s3,s4};
        yield return StartCoroutine(
            DialogueBox.Instance.SetDialogueBox(strings1, strings2, 2)
        );
        BackPackUI.Instance.SetItem(this.gameObject); //包含Destroy(gameObject);
    }
}

```
