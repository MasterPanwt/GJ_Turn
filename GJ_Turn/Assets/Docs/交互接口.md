# 交互接口 IInteractable
## 说明
包含 碰撞箱 和 Interact方法
相关可交互物体，可以继承这个接口来调用  
举例为PickUp脚本
## PlayerInteractor
这个要挂在玩家身上

## (C10UDS)脚本：物品名+Interactable
需要交互的物体挂上对应物品名的脚本
至少需要包含：
``` csharp
public class DeskInteractable : MonoBehaviour, IInteractable
{
    public Collider2D Collider { get; private set; }
    public void Awake()
    {
        Collider = GetComponent<Collider2D>();
    }
    private bool isInteracted { get; set; } = false; 
    public void Interact(PlayerInteractor player)
    {
        //逻辑
    }
}
```

## PickUp
这个脚本是接口测试，玩家接触带有这个脚本的触发器会出现E，  
然后按下会调用该函数的内容，捡起物体到背包，并将该物体摧毁，  
（由于背包界面没制作就先不放进背包）
