# 玩家控制与虚化系统

相关资产：`Player.prefab`、`PlayerController.cs`、`PlayerFadeController.cs`、`PlayerState.cs`、`PlayerStateMachine.cs`、`PlayerIdleState.cs`、`PlayerMoveState.cs`

虚化值系统相关资产：`FadeController.cs`

## 相关说明

若需要某对象拥有虚化值且可以通过手电筒照射更改，需要在该对象上挂`FadeController`。

若需要某对象挡住手电筒的光实现影子效果，需要在该对象上挂`Shadow Caster 2D`组件。

若需要某对象在检测手电筒照射中遮挡检测用射线，需要设置其`Layer`为`Flash Obstacle`。

（C10UDS：）函数Rampto(float to)，to=range(0f,1f)使物体的透明度百分比（从128到255）随时间均匀变化到to。

上面二步一般是一起做的，不过我觉得只做其中一步可能可以做解密关卡。

若希望某对象为小怪，带有被照强光就消除特性，需要挂`EnemyController`。

## 实现思路碎碎念

手电筒的光锥使用了Unity自带的`Light2D`。

在已知某对象需要进行手电筒照射检测时，先用数学方法检测其是否在手电筒光的锥形范围内，然后通过射线检测其与`Player`中间是否有`Flash Obstacle`层的障碍物。

在`PlayerController`中维护一个列表，其记录所有需要进行手电筒照射检测的对象，在`Update`方法中一一检测。

`FadeController`会在`Start`方法中将自己对应的对象加到列表中。

`PlayerFadeController`用`OnTriggerEnter2D`与`OnTriggerExit2D`事件维护了当前与Player碰撞的所有虚化对象的列表，每帧遍历列表，检查`FadeController`的虚化进度并据此更新玩家的`fadeProgress`。

`EnemyController`在收到`onDazzle`事件时检查自身对象是否于手电筒光锥中，是则销毁自身对象。
