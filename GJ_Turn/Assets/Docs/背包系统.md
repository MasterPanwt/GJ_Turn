# 背包系统

相关资产：`Inventory.prefab`、`BackPackManager.cs`、`Item.cs`、`ItemInBackPack.cs`、`SubmitBotton.cs`

## 说明

如果要将一个物体能被加入背包请添加`Item.cs`，并且将它简介一并填写（后续可能会弄个数据库来专门放这些数据）

使用时在对应交互脚本写上`BackPackUI.Instance.SetItem(this.gameObject);`。

## 实现思路

1. 先在背包界面创建6个格子数组每个格子带有`ItemInBackPack.cs`，可以记录当前格子的图标，简介和名字
2. 交互时找到空格子将对象的`Item`内数据填入`ItemInBackPack.cs`中
3. 提交时判断是否是由提交而打开的界面，才会出现提交按钮
4. 给每个格子加上按钮后可以调用函数`OpenIntroPanal()`点击出现简介
