# 音频对象池及背景音乐相关
## 枚举

如需修改请去AudioSourcePool脚本
``` cs
public enum SfxId
    {
        None = 0,//无音效
        // ── A. 玩家核心 ──────────────────────────────
        PlayerStep      = 10,   // 脚步
        FlashOn         = 11,   // 手电开（机械"咔"）
        FlashOff        = 12,   // 手电关（闷"嗒"）
        FlashBurst      = 13,   // 强光爆闪
        BatteryEmpty    = 14,   // 电池耗尽（HUD 抖动提示）

        // ── B. 虚化状态 ──────────────────────────────
        PhaseIn         = 20,   // 实体 → 虚化
        PhaseOut        = 21,   // 虚化 → 实体
        Tinnitus        = 22,   // 耳鸣（随虚化值反向，循环）

        // ── C. 交互 ─────────────────────────────────
        DoorOpen        = 30,   // 门开
        DoorLocked      = 31,   // 门锁拒绝（"开/拒绝 + 提示音"）
        DrawerOpen      = 32,   // 抽屉/柜子（初次、二次共用）
        Pick       = 33,   // 拾取
        ObjectPhaseOut  = 34,   // 虚化物品显形（必须对齐手电 1.2s）
        MirrorCompelete    = 35,   // 镜子照射 2s 完成
        InPhased =  36 ,//在虚化物品中被虚化

        // ── D. 床 ───────────────────────────────────
        BedRest         = 50,   // 小憩（重置手电实体化物）
        BedSleep        = 51,   // 入睡（进入下一轮）
        BedDeath        = 52,   // 虚化态上床 → 消散（一声闷响，之后全静）

        // ── E. 敌人 ─────────────────────────────────
        BigChaseLoop    = 60,   // 大怪追逐（循环）
        BigStun         = 61,   // 大怪被强光眩晕 3s

        // ── F. 轮次与叙事 ────────────────────────────
        WakeUp          = 70,   // 每轮醒来（四轮共用同一段）
        RoundTransition = 71,   // 切轮（0.5s 内完成，不要长转场）
        MachineInsert   = 72,   // 碎片入槽 ×4（音高逐次升高）
        MachineStart    = 73,   // 实体化机启动
        MachineLoop     = 74,   // 30s 读条（循环）
        MachineInterrupt= 75,   // 读条被打断
        EndingFlash     = 76,   // 白光
        EndingSilence   = 77,   // 黑屏后的完全静音

        SFXend          = 78,   //最后一个音效，用来判断用哪个音频混合器

        // ── G. 环境底噪 ──────────────────────────────
        AmbRoomAir      = 80,   // 室内空气声（卧室/客厅）
        AmbKitchen      = 81,   // 厨房冰箱低鸣
        AmbBathroom     = 82,   // 浴室滴水/管道

        BGMend          = 83,    //最后一个背景音乐

        // ── H. UI ──────────────────────────────────
        UiClick         = 90,   // 通用点击
        UiBackpackOpen  = 91,
        UiBackpackClose = 92,
        UiToast         = 93,   // 提示文字弹出

        UIend           = 94    //最后一个ui音效
    }
```

## 如何使用

1. 在你要播放的脚本写下`public AudioSourcePool audioPool;`
2. 将窗口中AudioSourcePool拖入
3. 调用函数即可，belike
`audioPool.PlaySound(testClip,AudioSourcePool.SfxId.PlayerStep);`  
其中，第一参数为音频，第二参数为SfxId的枚举类型
