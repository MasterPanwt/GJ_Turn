# ui界面说明

### 1. 虚化值ui
位置在UIPanel下面，命名为xuhuazhi，下方由虚幻值文本，及具体数值0-100%

这个虚化值拟定是长条状，如果可以想设计成渐变色，由深到浅的变化，到时会由脚本来调节长度

### 2.Fragment碎片数  
初级设想 纯文字 “碎片数4/4”  
高级设想 文字加图片 将图片分为4块，收集一片就多一张图片，将其填补完整
### 3. Map
设想，点击可以跳转到整体预览地图到时会用脚本修改画面（应该不用美术吧）  

### 电量ui
类似虚化值设计
