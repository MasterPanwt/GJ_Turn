# 场景切换

相关资产：

1. 在`SceneManagement`文件夹内 预制体`TransitionExit`、`TransitionEntrance`、`SceneLoader` 在`UI`文件夹内`ScreenFader`

2. 脚本`SceneEntrance.cs`、`SceneExit.cs`、`SceneLoader.cs`、`ScreenFader`

## 说明
1. Sceneloder是单例模式，切换场景不销毁，如果场景切换报错大概率是没有这个场景中没有`SceneLoader`,和`ScreenFader`
2. `ScreenFader`是黑屏的UI界面，`SceneLoader`是用来保存数据和记录出口和入口的
3. `TransitionExit`、`TransitionEntrance`出入口脚本，出口记得填你要加载的场景（这个后续会挂在床上结合交互），入口脚本只是起到一个定位效果（后续可以有些操作

## 实现思路
1. 在场景加载之前和后加上个让ui界面变黑和变白的协程函数`Fade`就能实现淡入淡出
2. 出口设置成触发器调用加载和淡出即可实现
